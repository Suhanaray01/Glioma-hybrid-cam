      What these metrics mean

      Accuracy: fraction of all images classified correctly. Balanced accuracy: average sensitivity across classes. Precision: when predicted as a class, how often it was correct. Sensitivity / recall: how many images of a class were found. Specificity: how many images outside that class were correctly rejected. F1: balance between precision and sensitivity. ROC AUC: how well the class scores rank positives above negatives; it does not measure calibration.
